Task 2 Layout Overview

This section demonstrates a traditional two-column layout constructed strictly using HTML <div> tags and CSS float positioning without relying on modern Flexbox or CSS Grid modules.

The sidebar floats to the left with a fixed percentage width, while the main content section floats to the right. Clearfix techniques are used to prevent container collapse.
