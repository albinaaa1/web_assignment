# Assignment Description

A  web development assignments focusing on semantic HTML5, modern CSS styling, layout architectures (Flexbox, standard Floats, CSS Grid), and interactive form elements.

---

## 📌 Tasks Overview

### 📍 Main Navigation Page (`index.html` & `style.css`)
* **Description:** A clean, responsive landing page serving as the central hub for navigating across all coursework assignments.

---

### 📍 Task 1: Personal Webpage (`1task.html` & `1task.css`)
* **Description:** A personal portfolio page introducing Albina Onlasyn, a Software Engineering student (Group SE-2527).
---

### 📍 Task 2: Traditional Webpage Layout (`2task.html` & `2task.css`)
* **Description:** A classic multi-column webpage layout built strictly using float-based CSS positioning.


---

### 📍 Task 3: Actor Tribute Page (`3task.html` & `3task.css`)
* **Description:** A tribute page dedicated to South Korean actor **Kim Bum**.


---

### 📍 Task 4: Table & Form Styling (`4task.html` & `4task.css`)
* **Description:** An interactive page combining data table formatting and a user feedback web form.

---

## 🛠️ Tech Stack & Concepts Covered

* **HTML5:** Semantic tags (`<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`), structured lists (`<ol>`, `<ul>`), form controls, and tables.
* **CSS3:** Flexbox layout, CSS Floats & Clearfix, Sticky positioning, CSS Media Queries for responsiveness, transitions, custom color palettes, and box-sizing normalization.
